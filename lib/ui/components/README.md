# components

여러 화면에서 재사용하는 위젯을 둡니다. 색 · 간격 · 글자는 `core/theme/` 토큰만 씁니다.

| 파일 | 용도 |
|---|---|
| `pressable.dart` | 눌리는 것의 기반 (누를 때 투명도 · 최소 터치 48 · 물결 없음). 예: 키패드 숫자 버튼 |
| `surface_box.dart` | 그림자 없는 면 상자 (필요할 때만 1px 테두리) |
| `skeleton_box.dart` | 불러오는 동안 자리를 잡아 두는 회색 상자 |
| `empty_state_view.dart` | 보여줄 내용이 없을 때의 안내 |

한 화면에서만 쓰는 위젯은 그 화면 폴더(`ui/pages/...`)에 두고, 두 화면 이상에서 쓰게 되면 여기로 옮기세요.
